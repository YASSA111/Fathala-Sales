## Navigation & Filters

The dashboard includes a left sidebar with filtering options:
- **اسم** (Name): Filter by city/location
- **السنة** (Year): Filter by year
- **الفترة** (Period): Filter by time period
- **الرياضية** (Category): Filter by business category

Additional filter options include:
- Branch selection
- Store name filters
- Product category filters
- Time period selectors

## Features

- **Real-time Data**: Dashboard displays current sales metrics
- **Multi-dimensional Analysis**: View data by branch, category, product, and time
- **Interactive Filters**: Customize views using the sidebar filters
- **Visual Analytics**: Multiple chart types for easy data interpretation
- **Performance Tracking**: Identify top and bottom performers quickly

## Technical Details

- **Data Range**: Covers sales across multiple branches and time periods
- **Currency**: Values displayed in USD ($)
- **Language**: Primary interface in Arabic with numerical data
- **Chart Types**: Bar charts, donut charts, and horizontal bar charts

## Usage

Use this dashboard to:
- Monitor overall sales performance
- Compare branch effectiveness
- Identify trending products and categories
- Make data-driven inventory decisions
- Track sales goals and targets
- Analyze sales patterns over time
